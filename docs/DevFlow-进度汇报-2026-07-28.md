## 一、项目简介

DevFlow 是一个基于 LangGraph 的多 Agent 协同软件工程平台。系统模拟真实软件团队的协作模式，用 4 个 AI Agent（需求分析、方案规划、代码开发、代码审查）通过 LangGraph 编排协作，自动完成从接收需求到修复 Bug 并通过测试的完整软件工程流程。

**核心流程**：提交需求 → Requirement Agent 分析 → Planner Agent 规划 → Developer Agent 生成代码 → 沙箱执行 pytest → Reviewer Agent 审查 → 测试失败自动返工（≤3 次）→ 通过后完成。

## 四、关键技术亮点

1. **三层 Patch 兜底**：Developer Agent 无法直接读取目标仓库源文件，生成的 diff 可能上下文不匹配。系统通过 git apply → 字符串精确替换 → 函数级模糊替换三层策略确保 patch 成功应用
2. **Agent 工具调用框架**：Developer Agent 可在沙箱中读文件、搜索代码、执行命令后再生成 patch。LLM 不支持时自动降级为纯 Prompt 模式
3. **Mock 双层开关**：Agent 和 Sandbox 的 Mock 独立控制（`DEVFLOW_USE_MOCK` / `DEVFLOW_USE_SANDBOX`），支持开发期快速迭代、真实 Agent + Mock 沙箱、全真实三种模式
4. **结构化输出校验**：JSON 提取 + Pydantic 验证 + 3 次格式修复重试 + JSON 自动修复（尾逗号移除），确保 Agent 输出可被下游可靠消费
5. **协作式取消与资源控制**：每个节点边界检查 `cancel_requested`，支持任务总超时（`deadline_at`）和 LLM 费用预算（`budget_limit_usd`）
6. **事件流与可观测性**：每个 Agent 调用记录 Token 消耗、费用、耗时、决策理由。SSE 端点支持前端实时展示
